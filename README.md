## What is BotBlocker?

**Blocks 99% of automated attacks before WordPress loads.** Three interception layers (wp-config.php → MU-plugin → main shield) stop bots, brute force, spam, and fake crawlers — saving 30-100ms and 5-20MB RAM per blocked request.

- **3,000+ active installs** · **8 languages** · **GDPR / CCPA compliant**
- 9 CAPTCHA modes including AI-resistant Shapes CAPTCHA
- 2,899 User-Agent signatures, FCrDNS fake crawler detection
- Payment gateway bypass for 150+ providers (Stripe, PayPal, WooCommerce)
- Full IPv4/IPv6 support, Cloudflare / DDoS-Guard compatible
- 2FA (TOTP), brute force protection, country/ASN blocking
- **Free core** — no crippled features. PRO from $11/mo.
